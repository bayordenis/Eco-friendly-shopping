# EcoMart — Persuasive E-Commerce for Eco-Friendly Choices

EcoMart is a web-based e-commerce application designed to encourage consumers to make more environmentally friendly purchasing decisions. The project explores how **persuasive user-interface (UI) techniques** can be incorporated into an online shopping environment to promote sustainable consumer choices.

## Project Overview

The project, titled **"Design and Evaluation of a Persuasive E-Commerce Interface for Promoting Eco-Friendly Consumer Choices,"** combines e-commerce, Human-Computer Interaction (HCI), and persuasive technology.

EcoMart provides users with an online shopping interface while incorporating sustainability-focused information and persuasive design elements to encourage consideration of environmental factors when making purchasing decisions.

## Key Features

* Eco-friendly product browsing
* Product information and shopping interface
* Sustainability-focused messaging
* Persuasive UI elements
* Environmental/carbon-related information
* User-friendly e-commerce interface
* Responsive web design
* Usability evaluation

## Objectives

The main objectives of the project are to:

1. Design and develop a persuasive e-commerce interface prototype.
2. Incorporate persuasive design techniques that encourage eco-friendly choices.
3. Implement the proposed interface as a functional web application prototype.
4. Evaluate the usability and effectiveness of the developed interface.

## Technologies

The project is implemented as a modern web application using web development technologies, with the source code maintained in this repository.
